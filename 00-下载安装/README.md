# 轻量版：直接下载使用（Windows x64）

**普通用户不用下载源码，不用安装 Node.js/npm。点击下面的 EXE 下载，双击即可。**

## 首选：0.3.1 EXE

[⬇ 下载 轻量版 0.3.1 EXE](https://github.com/Mizusamada/TerraDeskMateLight/releases/download/v0.3.1/TerraDeskMateLight-Setup-0.3.1.exe)

只内置阿米娅；其他角色按需下载导入，不附语音环境和独立权重。

这是完整离线安装包，下载一个 EXE 即可，不需要旧版或更新 ZIP。安装后从开始菜单打开。

### 不想安装：自解压便携 EXE

[⬇ 下载轻量版便携解压 EXE](https://github.com/Mizusamada/TerraDeskMateLight/releases/download/v0.3.1/TerraDeskMateLight-Portable-0.3.1.exe)

双击、选择解压位置、完成后打开目录中的 TerraDeskMate.exe。保持整个解压文件夹完整，不能只复制程序 EXE。便携解压包不注册卸载项；个人设置仍使用软件原有用户数据目录。

[下载 SHA256 校验清单](https://github.com/Mizusamada/TerraDeskMateLight/releases/download/v0.3.1/DIRECT-DOWNLOAD-SHA256.json)。

## 三步开始

1. 下载上面的 EXE，双击按向导完成。
2. 打开软件控制中心。启动不会自动生成桌宠，点击“显示”才出场。
3. 模型、动作、原声等基础功能可以使用；AI 对话需填写自己的服务配置/密钥。ASR、外部语音推理及训练按所选版本另行配置。独立角色权重缺失时不能宣称其AI音色已可用。

## 下载并导入角色

[打开按角色分类的下载目录](角色下载目录.md)。下载需要的角色基础包 → 解压 → 控制中心“下载管理” → “导入角色文件夹 · 自动配置” → 选择含 manifest.json 的角色文件夹。软件导入后自动选择对应角色。语音权重需要另外下载导入，不能把基础包当训练权重。
